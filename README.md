# OmniTriage AI 🚑 (PS 05: Real-Time Voice & Multimodal Agents)

An intelligent, low-latency real-time voice and multimodal assistant designed for instant emergency medical triage and symptom ingestion. Built for the **AI Build Challenge 2026**.

## 🚀 Features
* **Sub-Second Response Architecture:** Designed for lightning-fast audio stream processing.
* **Multimodal Ingestion:** Handles spoken symptom inputs alongside visual reports/images.
* **Automated Clinical Structuring:** Parses raw speech into clean, prioritized JSON triage reports.
* **Safety Guardrails:** Built-in protocol validation for reliable medical workflows.

---

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Uvicorn
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Fetch API)
* **AI Integration:** Ready for Gemini Live / OpenAI Realtime API web-socket pipelines
